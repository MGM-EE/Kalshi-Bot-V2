First time? Connect Kalshi in three steps
  1. In Kalshi account settings, create an API key. Keep its API key ID and downloaded private-key file.
  2. Open CONNECT_KALSHI.bat in this project's folder. Enter the ID, use Choose key file, and save the encrypted copy. You do not need to type a private-key path.
  3. Restart the app. Check the API access and price-data cards above. A saved key does not guarantee that every feed is available.
Never paste your key into this page or a chat. If your downloaded private key is lost, create a replacement key at Kalshi.

      
What do the buttons and statuses mean?
Enable paper entries allows automatic buys with pretend money when all rules and data checks pass. It does not guarantee a trade. Pause new entries stops automatic buys; existing positions can still exit. Emergency paper exit asks the bot to close paper holdings when valid prices allow. A browser disconnect does not change these saved controls.
Full market recording saves observations for replay. It does not train a prediction model automatically. Paper trades and settings are saved separately even when full recording is off.
